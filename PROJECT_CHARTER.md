# Project Atlas - Project Charter

## Vision

Project Atlas is an Enterprise Platform Engineering Laboratory designed to simulate the work of a modern Platform Engineering and SRE team.

## Mission

Build a complete self-hosted enterprise platform from scratch while learning technologies, processes and engineering practices used by modern infrastructure teams.

## North Star

**Build once. Automate forever.**

## Engineering Principles

- Everything as Code
- Automation First
- Documentation Matters
- Security by Design
- Open Source First
- Learn by Building
- Learn by Breaking
- Continuous Improvement

## Scope

Project Atlas includes:

- Linux Engineering
- Git and source control
- CI/CD
- Containers
- Kubernetes
- GitOps
- Infrastructure as Code
- Configuration Management
- Observability
- Automation with n8n
- Incident Response
- Platform Operations
