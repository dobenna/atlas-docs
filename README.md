## 📖 Overview

Project Atlas is an enterprise-grade Platform Engineering and Site Reliability Engineering (SRE) laboratory designed to simulate the architecture, workflows, tools and operational practices used by modern infrastructure teams.

Unlike traditional DevOps tutorials, Atlas focuses on building and operating an entire enterprise platform from the ground up using real engineering practices.

The project is centered on Linux, Infrastructure as Code, Kubernetes, GitOps, CI/CD, Observability, Automation and Operational Excellence.

---

# 🎯 Vision

Design, build, operate and continuously improve a modern self-hosted enterprise platform capable of supporting cloud-native applications.

---

# 🚀 Mission

Build a complete Platform Engineering ecosystem using production-oriented methodologies while documenting every architectural decision, implementation and operational procedure.

# 🌍 Atlas Ecosystem

Project Atlas is composed of multiple repositories.

| Repository | Purpose |
|------------|---------|
| atlas-docs | Architecture, documentation, ADRs, standards and runbooks |
| atlas-workstation | Platform Engineer workstation configuration |
| atlas-platform | Infrastructure as Code and platform bootstrap |
| atlas-kubernetes | Kubernetes manifests and GitOps |
| atlas-monitoring | Monitoring, logging and observability |
| atlas-automation | n8n workflows and intelligent automation |
| atlas-pipelines | Jenkins, GitHub Actions and GitLab CI/CD |
| atlas-apps | Sample applications used for deployment |
| atlas-ops | Operational scripts and utilities |
